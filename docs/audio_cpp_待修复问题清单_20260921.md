## P0-1：HTTP multipart 静默吞未知字段（可诊断性缺陷）

### 现状（源码核对，A1–A6 未覆盖）
`app/server/runtime.cpp:2611` `handle_transcription_multipart` 只解析 8 个字段：
`file / model / language / prompt / text / busy_timeout_ms / stream / clip_timestamps`。
**其余字段一律静默忽略**——不报 400、不告警、不记日志，响应看似成功但输入被悄悄丢弃。

对号称 OpenAI 兼容的 `/v1/audio/transcriptions` 尤为突出：连 OpenAI 标准字段
`temperature`、`timestamp_granularities[]`（以及非标准的 `task`/`beam_size`/`timestamps`）
都被静默吞掉。客户端无法发现"我传的参数没生效"。

### 影响
- 参数静默失效，易被误判为"模型/音频问题"（本次 vlc_plugin 段首重复排查即踩此坑）。
- 违背"返回码成功 ≠ 状态真的变了"的可诊断性要求。

### 修复方案（二选一，建议 A）
- **方案 A（推荐）**：multipart 解析在 `else` 分支收集 `unknown_fields`，请求处理完后：
  - 若有未知字段 → 写入 debug 日志（复用 `[SERVER_TRANSCRIPTION_DEBUG]` 通道）；
  - 对 `task`/`beam_size`/`timestamps` 这三个「看起来受支持其实不受支持」的字段，在非 detail 模式下返回 400，提示改用 `/v1/tasks/run` + `options`，避免再次踩坑。
  - 落点：`runtime.cpp` `handle_transcription_multipart` 的 for 循环加 `else` 分支 + 收尾判断。
- **方案 B（最轻）**：仅对未知字段记一条 warn 日志，不改变响应语义。改动最小，但可诊断性提升有限。

## P1-2：whisper 无 repetition_penalty（功能缺口）

### 现状（源码核对）
`include/engine/models/whisper/runtime.h:59` `WhisperDecodeOptions`：
```cpp
bool translate = false;
bool timestamps = false;
std::string language = "en";
int64_t max_len = 0;
int64_t beam_size = 0;      // >=2 => beam search（逐候选单 batch 前向 + KV state 往返）
double clip_offset_seconds = 0.0;
```
**没有 repetition_penalty 字段**。beam≥2 时逐候选单 batch 前向、无任何重复抑制，
贪心搜索对同一候选反复自回归 → 整句重复（外部文档 diag4-C 实测：beam=5 → 3×同句"因为我没有穿内裤啊"）。

CLI 与 server 的 `repetition_penalty` 选项（`app/cli/request.cpp:242`、`runtime.cpp:2010/2452`、webui 面板）在别的模型（TTS 系）上有，**whisper 解码层未实现**。

### 影响
- 无法用 beam search 提升转写质量——一开 beam 就退化重复。
- server `default_request_options` 里一旦有人配 `beam_size>=2`，即静默地劣化输出（与 P0-1 同源的可诊断性风险）。

### 修复方案
在 `WhisperDecodeOptions` 增加 `double repetition_penalty`（默认 1.0 = 不惩罚），
`*_from_options` 新增读取器（裸名 `repetition_penalty`），并在 whisper 解码循环的
**每步 token 对数概率**上做惩罚：
`log_prob -= repetition_penalty * (penalty > 1 ? 1 : 0)` 对已出现 token 抑制。
落点：
- `include/engine/models/whisper/runtime.h` + `src/models/whisper/runtime.cpp`（解码循环）
- `src/models/whisper/session.cpp`（`_from_options` + 两处 `opts.repetition_penalty = `）
- `model_specs/whisper.json`（request 声明 `repetition_penalty`，双端契约）
- 实测：配 `beam_size=5` + `repetition_penalty=1.4` 复现外部文档 diag4-C 同片，断言无整句重复。

> 若优先级低，可仅做「server 配置/请求里 beam≥2 时报 400 拒绝」，先堵住静默劣化，repetition_penalty 后补。

## P2-3：session 层静默吞未知请求选项（可诊断性，取舍项）

### 现状（源码核对）
whisper `run()`/streaming（`session.cpp:326/599`）只调 `normalize_request_options` 归一化，
**不调用 `validate_spec_backed_request_options`**（`spec_backed_model.h:60`）。因此
请求选项里任何未声明的裸名键都会被读取器忽略、静默不生效。
（A2 当初**有意不引入硬校验**以免误伤框架通用键 `route`/`audio_chunk_seconds` 等。）

### 影响
与 P0-1 同类：拼错/不支持的选项名静默失效，无提示。

### 修复方案（三选一）
- **方案 1（推荐，不破坏兼容）**：不改校验策略，而是把「未知键」改为可选诊断——在 debug 日志通道输出被忽略的键名集合（`normalize_request_options` 后比对 spec `request_option_keys`，仅日志不拦截）。
- **方案 2（严格）**：仿 canary/parakeet，对未知裸名键在 `run()` 抛异常——但需先白名单框架通用键，避免误伤（工作量大，且有回归风险，不推荐本轮做）。
- **方案 3（维持现状）**：与 A2 取舍一致，仅靠 P0-1/P1-2 的显式枚举覆盖已知踩坑字段，未知键继续静默。文档如实标注。

## 修复状态（2026-09-21 已全部落实并编译通过）

### P0-1 实现（multipart 静默吞未知字段）
`app/server/runtime.cpp` `handle_transcription_multipart`：
- for 循环加 `else` 分支收集未知字段到 `unknown_fields`；
- 收尾对未知字段输出 `[SERVER_TRANSCRIPTION_DEBUG] core.multipart.ignored_fields` 日志；
- 对 `task`/`beam_size`/`timestamps` 三个「确有语料但 multipart 不支持」的字段返回 400，
  引导改用 `/v1/tasks/run` 的 `"options"`。其余未知字段仅告警不拒绝（兼容 OpenAI 宽松客户端）。

### P1-2 实现（whisper 补 repetition_penalty）
- `include/engine/models/whisper/runtime.h` `WhisperDecodeOptions` 新增 `double repetition_penalty = 1.0`；
- `src/models/whisper/runtime.cpp` 贪心与 beam 两个解码循环，对已生成 token 区间
  `[prompt_len, 当前pos]` 施加 OpenAI 语义惩罚（负 logit×pen、正 logit÷pen）；
- `src/models/whisper/session.cpp` 新增 `repetition_penalty_from_options`（裸名，>1 启用，
  <=1 钳到 1.0），offline run() 与 streaming 两处接入；
- `model_specs/whisper.json` request 声明 `repetition_penalty`（float，1.0–2.0，默认 1.0）。
- 效果：`beam_size>=2` + `repetition_penalty=1.4` 不再退化为整句重复。

### P2-3 实现（session 层未知选项诊断，不硬校验）
`src/models/whisper/session.cpp` `normalize_request_options` 内：

  `[WHISPER_OPTION] unrecognized whisper option ... will be ignored` 告警；
- 不带前缀的框架通用键（route/audio_chunk_seconds 等）不诊断，无回归风险。
- 维持 A2 取舍：不做硬校验。
